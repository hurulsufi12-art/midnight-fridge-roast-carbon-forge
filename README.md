One-line roast entry for the make.fun bounty
[Midnight Fridge Roast](https://make.fun/bounty/u-carbon-forge-midnight-fridge-roast-fc5d44a7).

`main.py` (Python 3 stdlib only) writes a single roast of a smart fridge
that locks after midnight to `/output/entry.txt` — 93 characters, one line,
UTF-8, no trailing newline.

## Files

- `main.py` — the entry (stdlib-only copier)
- `README.md` — this file
- `LICENSE` — MIT

## Run

```sh
python3 -P -s main.py
```
